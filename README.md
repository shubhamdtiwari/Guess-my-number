# 🎯 Guess My Number

A fun and interactive number-guessing game built using HTML, CSS, and JavaScript. Challenge yourself to guess the secret number and test your logical thinking!

---
📌 **About the Project**

Guess My Number is a browser-based game in which the player tries to guess a randomly generated secret number within a given range. After each guess, the game provides feedback to help the player determine whether the guess is too high or too low.

---
✨ **Features**

- 🎲 Random secret number generation
- 🔢 User input for guessing the number
- 📈 Feedback for high and low guesses
- 🏆 Score tracking
- ❤️ High score tracking
- 🔄 Restart the game and play again
- 📱 Simple and interactive user interface
---

🛠️ **Technologies Used**

- HTML5 — Structure of the application
- CSS3 — Styling and layout
- JavaScript — Game logic, event handling, and DOM manipulation
---


🚀 **Getting Started**

1. Clone the Repository

  - git clone https://github.com/shubhamdtiwari/Guess-my-number

2. Navigate to the Project Directory

  - cd guess-my-number

3. Run the Project

  - Open the "index.html" file in your web browser.

---


🎮 **How to Play**

1. Start the game.
2. Enter your guess in the input field.
3. Submit your guess.
4. Read the feedback:
   - Too high! — Try a smaller number.
   - Too low! — Try a larger number.
   - Correct! — You guessed the secret number!
5. Try to achieve the highest possible score.
6. Restart the game to play again.
